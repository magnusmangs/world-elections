# World Elections

A world map of upcoming national elections. Click a country to see its parties, leaders and policies.

- `index.html`, `styles.css`, `app.js`: the static site (no build step on Vercel).
- `data/countries/<ISO3>.json`: one file per country. Edit these.
- `data/elections.json`: generated by `python3 scripts/build.py`. Never edit by hand.
- `data/watchlist.json`: countries to research next.

Updated weekly by a scheduled Claude task that researches changes, edits country files, rebuilds and pushes. A GitHub Action (.github/workflows/deploy.yml) redeploys to Vercel on every push to `main`. It needs the repo secret `VERCEL_TOKEN`.

## Languages

The site shows one language at a time: Icelandic by default, English with the IS / EN toggle in the top navigation
(`i18n.js`, saved per browser; `?lang=en` or `?lang=is` forces one). Static text sits in the HTML in Icelandic with the
English in `data-en` attributes; scripts use `window.LANG`. Data carries both languages:
- Country files: English fields plus Icelandic twins with the suffix `Is` (checked by `build.py`).
- News items: `titleIs`/`summaryIs` plus `titleEn`/`summaryEn` (checked by `news.py`).

## Fréttir (news)

- `frettir.html`, `frettir.js`: Icelandic news page, merged from all sections.
- `scripts/news.py`: builds `data/news.json` at deploy time from SECTIONS (third-party articles, election highlights). Add a function to SECTIONS to plug in a new part of the site.
- `data/news/articles.json`: third-party election news, own-words summaries with outlet and link. Validated against `data/news/sources.json` (allowed outlets), length and quotation limits.
- `NEWS.md`: daily research procedure used by the scheduled task.
- `data/news/outlets.json`: top outlets per country (with type: public broadcaster, state media, newspaper...) and RSS feeds.
- `scripts/headlines.py`: hourly; collects headlines + links only (no article text) and indexes them by country: domestic coverage vs foreign coverage. Keywords in `data/news/keywords.json` plus leader surnames from the election data.
- `.github/workflows/update-headlines.yml`: hourly refresh and deploy. Headlines are generated, not committed.
- Sjónarhorn items (`"type": "sjonarhorn"` in articles.json) compare how outlets in different countries frame the same story; validated to need 2+ outlets from 2+ countries.

## Brennidepill (focus)

Stories emerging from one country with conflicting reports, taken apart objectively: confirmed vs disputed facts, each
side's case, how outlets in different camps frame it, timeline and what comes next.
- `brennidepill.html`, `brennidepill.js`, `brennidepill.css`: list at `/brennidepill`, topic at `/brennidepill/<id>`.
- `data/brennidepill/<id>.json`: one file per topic. `scripts/brennidepill.py` validates them (Icelandic twins, cited
  sources exist, "confirmed" needs two outlets, two or more camps) and writes `index.json`.
- Recent topics also show in the Fréttir feed and as an "Í brennidepli" link in the country panel.
- `BRENNIDEPILL.md`: how to research and write a topic.

## Myndir (images)

- `scripts/media.py`: freely licensed images from Wikimedia Commons, found through Wikidata. Candidate photos by exact name plus citizenship, flags by ISO code. Only public domain, CC0, CC BY and CC BY-SA files are kept; every image is shown with author and licence and links to its Commons page. Writes `data/media/media.json`.
- `data/media/presskits.json`: company press rooms (linked). Press-kit images are only embedded after that company's terms for press use are checked and recorded.

## Bandaríkin (US midterms)

- `bandarikin.html`, `bandarikin.css`, `bandarikin.js`: map of every state (Senate, governors, House) with Cook ratings,
  candidates, current House delegations, competitive districts and local news. Map: `assets/us-states-albers-10m.json`
  (us-atlas, pre-projected).
- `scripts/us_races.py` builds `data/us/races.json`; `scripts/us_news.py` collects headlines from each state's
  States Newsroom outlet or partner and from national outlets across the spectrum (titles and links only).
- Election night: `data/us/live.json`, see UPDATING.md step 14.

## Spjall (chat)

`api/ask.js` is a Vercel serverless function behind the "Spyrja" button on every page (`chat.js`, `chat.css`).
It answers only from the site's own data for what the reader has open: a country (`data/countries/ISO3.json` plus
article-based news for that country) or the news front page. Context is built in `lib/context.js`. Headline-only items are never used.

Provider is chosen by environment variables in the Vercel project (Settings, Environment Variables):
- `MISTRAL_API_KEY`: free Experiment plan at console.mistral.ai (rate-limited, EU-based). Optional `MISTRAL_MODEL`, default `mistral-large-latest` with `mistral-small-latest` as fallback.
- `GROQ_API_KEY`: free tier (about 1,000 requests a day). Optional `GROQ_MODEL`.
- `ANTHROPIC_API_KEY`: used first when set (best Icelandic, paid). Order: Anthropic, then Mistral, then Groq. Optional `ANTHROPIC_MODEL`.
With neither set the widget replies that chat is not active yet. Questions are capped at 500 characters,
30 per hour per IP (best effort), and nothing is logged or stored.
