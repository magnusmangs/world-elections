# World Elections

A world map of upcoming national elections. Click a country to see its parties, leaders and policies.

- `index.html`, `styles.css`, `app.js`: the static site (no build step on Vercel).
- `data/countries/<ISO3>.json`: one file per country. Edit these.
- `data/elections.json`: generated by `python3 scripts/build.py`. Never edit by hand.
- `data/watchlist.json`: countries to research next.

Updated weekly by a scheduled Claude task that researches changes, edits country files, rebuilds and pushes. A GitHub Action (.github/workflows/deploy.yml) redeploys to Vercel on every push to `main`. It needs the repo secret `VERCEL_TOKEN`.
